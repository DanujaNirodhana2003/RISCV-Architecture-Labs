# CO2070 Computer Architecture Labs
This repository contains the laboratory exercises and implementations for the **CO2070: Computer Architecture** module. The labs primarily focus on understanding processor architecture, data paths, control units, and memory hierarchy using **RISC-V** assembly and **Verilog HDL**.

## Directory Structure
* **Lab01:** Introduction to RISC-V assembly and Ripes simulator.
* **Lab02:** Control structures and memory arrays in RISC-V.
* **Lab03:** Introduction to Verilog HDL and basic combinational circuits.
* **Lab04:** Sequential circuits and Finite State Machines (FSM).
* **Lab05:** Memory hierarchy and Cache memory implementation.
* **Lab06:** Single-cycle processor datapath implementation in Verilog.
* **Lab07:** Pipeline processor implementation in Verilog.
* **Lab45:** Extended exercises covering sequential logic and basic caches.
  

## Tools Used
* [Ripes](https://github.com/mortbopet/Ripes) - RISC-V Simulator
* Verilog Simulator (Icarus Verilog / GTKWave)
